# B MARKET — Flutter starter

واجهة أولية لتطبيق تسوق متعدد المتاجر باللغة العربية (RTL).

## الموجود حالياً
- شاشة رئيسية وهوية تركواز/برتقالي.
- أقسام: سوبر ماركت، مخبز، ألبان، عناية بالبشرة، خضروات.
- بطاقات منتجات تجريبية وأسعار توضيحية بالجنيه السوداني.
- سلة موحدة محلية داخل التطبيق.
- تنقل سفلي بين الرئيسية والمتاجر والسلة والحساب.

## التشغيل
1. ثبّت Flutter SDK و Android Studio.
2. من مجلد المشروع نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
3. لبناء APK تجريبي:
   ```bash
   flutter build apk --debug
   ```
   الناتج عادةً في `build/app/outputs/flutter-apk/app-debug.apk`.

## تنبيه مهم
هذه واجهة MVP تجريبية وليست تطبيقاً إنتاجياً. المنتجات والأسعار بيانات ثابتة للعرض فقط.
يلزم إضافة Backend وقاعدة بيانات ومصادقة وحسابات المتاجر والمناديب، وتقسيم الطلبات حسب المتجر،
وتكامل دفع إلكتروني مناسب للسودان، وإدارة التوصيل والإشعارات قبل الإطلاق الحقيقي.
